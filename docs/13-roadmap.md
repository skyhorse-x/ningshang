# 开发路线图

## 1. 开发阶段

### Phase 1：基础搭建（预计 5 天）

| 任务 | 预计工期 | 说明 |
|------|----------|------|
| 项目初始化 | 1 天 | Spring Boot + Vue 3 项目骨架 |
| 数据库设计 | 0.5 天 | 建表脚本 + 数据初始化 |
| 后端基础 | 1.5 天 | Entity + Repository + Service + Controller |
| 前端基础 | 1 天 | 路由 + 布局 + 主题 |
| API 联调 | 1 天 | 接口测试 + 前后端联调 |

### Phase 2：页面开发（预计 7 天）

| 任务 | 预计工期 | 说明 |
|------|----------|------|
| 首页 | 1 天 | 轮播 + 新闻 + 产业 + 业务 |
| 集团概况 | 2 天 | 7 个子页面 |
| 新闻中心 | 1 天 | 列表 + 详情 |
| 集团产业 | 1 天 | 概览 + 2 个子页面 |
| 联系宁商 | 1.5 天 | 联系方式 + 留言 + 招聘 |
| 样式调整 | 0.5 天 | 响应式 + 细节优化 |

### Phase 3：测试与部署（预计 3 天）

| 任务 | 预计工期 | 说明 |
|------|----------|------|
| 功能测试 | 1 天 | 页面 + API + 兼容性 |
| 性能优化 | 1 天 | 加载速度 + 缓存 |
| Docker 部署 | 1 天 | Dockerfile + Compose |

## 3. 里程碑

| 里程碑 | 交付物 | 预计完成 |
|--------|--------|----------|
| M1 | 后端 API 全部就绪 | Day 5 |
| M2 | 前端页面全部完成 | Day 12 |
| M3 | 测试通过 + 部署上线 | Day 15 |

## 4. 开发顺序建议

1. 先后端 → 后前端（API 契约先行）
2. 先布局 → 后页面（组件复用）
3. 先 P0 功能 → 后 P1 功能
4. 先核心流程 → 后边缘功能
