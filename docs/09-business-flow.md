# 核心业务流程

## 1. 首页浏览流程

```
用户访问 / → 前端请求 GET /api/home → 后端查询新闻+子公司数据 → 返回 JSON → 前端渲染页面
```

## 2. 新闻浏览流程

```
用户点击新闻中心 → 前端请求 GET /api/news → 后端分页查询 → 返回列表 → 前端渲染
用户点击新闻 → 前端请求 GET /api/news/{id} → 后端查询详情 → 返回数据 → 前端渲染
```

## 3. 在线留言流程

```
用户填写表单 → 前端校验 → POST /api/messages → 后端校验+保存 → 返回成功 → 前端提示
```

### 3.1 留言状态机

```
[提交] → [待审核]（Phase 2 后台审核）→ [已发布] / [已拒绝]
```

## 4. 集团产业浏览流程

```
用户点击集团产业 → 前端请求 GET /api/subsidiaries → 后端查询 → 返回列表 → 前端渲染卡片网格
用户点击子公司 → 跳转到产业子页面 → 展示详细信息
```

## 5. 数据初始化流程

```
Spring Boot 启动 → CommandLineRunner 执行 → 检查数据是否存在 → 不存在则插入初始数据
```

## 6. 跨域请求流程

```
前端 dev server (localhost:5173) → 预检请求 OPTIONS → 后端 CORS 校验 → 允许 → 实际请求
```
