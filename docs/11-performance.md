# 性能设计

## 1. 性能目标

| 指标 | 目标值 |
|------|--------|
| 页面首屏加载 | < 3s |
| API 响应时间（P95） | < 500ms |
| 数据库查询 | < 200ms |
| 并发用户数 | 100+ |
| 静态资源加载 | < 1s |

## 2. 前端性能优化

### 2.1 构建优化
- 使用 Vite 构建，支持 Tree Shaking
- 代码分割（Code Splitting）
- 路由懒加载
- 图片压缩（WebP 格式）

### 2.2 运行时优化
- 组件按需加载
- 图片懒加载（loading="lazy"）
- 防抖/节流
- 虚拟滚动（长列表）

### 2.3 缓存策略
- 静态资源：强缓存（Cache-Control: max-age=31536000）
- API 数据：协商缓存（ETag）
- 浏览器缓存：localStorage 存储用户偏好

## 3. 后端性能优化

### 3.1 数据库优化
- 合理索引（见 04-database.md）
- 分页查询（Pageable）
- N+1 查询防护（@EntityGraph）
- 连接池配置（HikariCP）

### 3.2 缓存策略（Phase 2）
- Redis 缓存热点数据
- 缓存过期时间：5-30 分钟
- 缓存穿透防护：布隆过滤器

### 3.3 异步处理（Phase 2）
- 留言通知：异步发送邮件
- 日志记录：异步写入

## 4. 容量规划

| 资源 | Phase 1 | Phase 2 |
|------|---------|---------|
| CPU | 1 核 | 2 核 |
| 内存 | 512MB | 2GB |
| 数据库 | 1GB | 5GB |
| 静态存储 | 100MB | 500MB |

## 5. 监控指标（Phase 2）

- 接口响应时间
- 错误率
- 数据库连接数
- 缓存命中率
- 内存使用率
