# 产品需求文档（PRD）

## 1. 项目概述

### 1.1 项目定位
安徽宁商科技集团官方网站是企业对外品牌展示、权威信息发布的核心窗口，面向客户、合作伙伴及社会各界。

### 1.2 项目目标
- 使用 Spring Boot + Vue 3 + Element Plus + MySQL 重构现有官网
- **完整保留**原有视觉设计风格和背景图片
- 提升网站可维护性、可扩展性和性能
- 建立标准化开发流程和规范

### 1.3 用户画像

| 用户类型 | 描述 | 核心需求 |
|----------|------|----------|
| 潜在客户 | 寻找合作伙伴的企业 | 了解公司实力、业务范围 |
| 求职者 | 寻找就业机会的人才 | 了解企业文化、招聘岗位 |
| 合作伙伴 | 已有合作的企业 | 查看新闻动态、联系方式 |
| 媒体/记者 | 新闻采访 | 获取企业资讯、联系方式 |

### 1.4 用户角色

| 角色 | 权限 |
|------|------|
| 匿名用户 | 浏览所有公开页面 |
| 管理员（预留） | 管理新闻、留言、招聘信息 |

### 1.5 MVP 范围

**包含：**
- 首页（轮播 + 新闻 + 产业 + 业务）
- 集团概况（简介/致辞/大事记/团队/荣誉/党建/文化）
- 新闻中心（列表 + 详情）
- 集团产业（概览 + 建筑/软件板块）
- 联系宁商（联系方式 + 在线留言 + 人才理念 + 招聘岗位）

**不包含：**
- 管理后台（Phase 2）
- 多语言（Phase 2）
- 搜索引擎（Phase 2）
- 移动端 APP（Phase 3）
