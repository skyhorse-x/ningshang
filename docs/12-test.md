# 测试设计

## 1. 测试策略

### 1.1 测试金字塔

```
        /  E2E 测试  \
       / 集成测试    \
      / 单元测试     \
     /_______________\
```

### 1.2 测试覆盖率目标

| 类型 | 覆盖率目标 |
|------|-----------|
| 行覆盖率 | >= 80% |
| 分支覆盖率 | >= 70% |
| 核心业务 | 100% |

## 2. 单元测试

### 2.1 后端单元测试
- 框架：JUnit 5 + Mockito
- 测试 Service 层业务逻辑
- 测试 Repository 层查询
- 测试工具类

### 2.2 前端单元测试
- 框架：Vitest
- 测试工具函数
- 测试组件逻辑
- 测试 Store

## 3. 集成测试

### 3.1 后端集成测试
- 测试 Controller → Service → Repository 链路
- 使用 @SpringBootTest
- 使用 H2 内存数据库（测试环境）

### 3.2 前端集成测试
- 测试组件交互
- 测试路由跳转
- 测试 API 调用

## 4. E2E 测试

- 框架：Cypress / Playwright
- 覆盖核心业务流程：
  - 首页浏览
  - 新闻列表 → 详情
  - 在线留言提交
  - 页面导航

## 5. 性能测试

- 工具：JMeter / wrk
- 测试场景：
  - 首页并发访问（100 用户）
  - 新闻列表分页查询
  - 留言提交

## 6. 安全测试

- SQL 注入测试
- XSS 测试
- CSRF 测试
- 接口权限测试

## 7. 兼容性测试

- Chrome（最新版）
- Firefox（最新版）
- Safari（最新版）
- Edge（最新版）
- 移动端 Safari（iOS）
- 移动端 Chrome（Android）

## 8. 回归测试

- 每次发版前执行
- 自动化测试套件
- 核心功能冒烟测试
